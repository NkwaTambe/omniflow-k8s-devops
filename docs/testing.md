# Testing Strategy for OmniFlow Frontend

## Overview
The OmniFlow frontend now has a **comprehensive test suite** built with **Vitest** and **React Testing Library**. The suite is split into:

| Type | Location | Purpose |
|------|----------|---------|
| **Unit Tests** | `src/tests/unit/` | Test individual components in isolation (e.g., button click, rendering). |
| **Integration Tests** | `src/tests/integration/` | Verify that multiple components work together (e.g., App renders correctly, routing, data‑fetching hooks). |
| **Setup** | `src/test/setup.ts` | Global test utilities – imports `@testing-library/jest-dom` matchers and can host MSW configuration. |

## Running Tests Locally
```bash
# install deps (if not already) from the project root
cd src
npm ci

# run all tests with coverage report
npm run test:coverage
```
The coverage report is generated under `src/coverage/` (HTML viewable via `npm run test:coverage` or open `src/coverage/index.html`).

## CI Integration
The GitHub Actions workflow (`.github/workflows/ci.yml`) contains a **test job** that:
1. Checks out the code.
2. Sets up Node 20 with caching.
3. Installs dependencies (`npm ci`).
4. Executes `npm run test:coverage`.
5. Uploads the coverage artifact (`coverage-report`).

No further changes are required – the workflow automatically picks up any new test files placed under `src/tests/`.

## Adding New Tests
1. **Create a test file** under `src/tests/unit/` or `src/tests/integration/`.
2. Import the component or hook you want to test.
3. Use `render`, `screen`, and `fireEvent` from `@testing-library/react`.
4. Ensure the test file name ends with `.test.tsx` (or `.test.ts`).
5. Run the local test command to verify it passes before committing.

## Coverage Threshold (optional)
If you wish to enforce a minimum coverage, add a `coverage` block to `vite.config.ts`:
```ts
coverage: {
  reporter: ['text', 'json', 'html'],
  thresholds: { lines: 80, functions: 80, branches: 80, statements: 80 },
},
```
The CI will then fail when coverage drops below the specified percentages.
